# Introduction-loop metric recipe

Status: draft measurement handoff only. No invitation, referral request, or
reward has been sent.

- Qualified introduction: an eligible reuser identifies a colleague with the
  same documented evidence problem.
- Referred user's first value: the colleague reaches the first evidence-backed
  decision value event.
- Referred user's reuse: the colleague repeats that value event in the agreed
  maturity window.
- Activation-based loop coefficient: referred users reaching first value divided
  by eligible reusers in the same mature cohort.

Baseline and target: `null` until observed data exists. Owner: product-owner.
Counter-metric: unsupported decision rate and support capacity per user.
