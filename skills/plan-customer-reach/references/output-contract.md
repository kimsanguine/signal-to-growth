# Output contract

## `reach-plan.json`

Require:

- `research_question`
- `decision_supported`
- `segment_hypotheses`
- `inclusion_criteria`
- `exclusion_criteria`
- `channels`
- `capacity`
- `consent_policy`
- `retention_policy`
- `sampling_risks`
- `external_send` set to `false`

## `contact-drafts.md`

Include purpose, expected time, incentive, voluntary participation, data use, and a clear draft-only label. Do not include real contact details in a public artifact.

## `recruitment-log.csv`

Use pseudonymous candidate IDs with `segment`, `channel`, `status`, `consent_state`, and `notes`. Keep direct contact data in an approved private system, not this file.

## Completion gate

The plan is ready for human review when every segment supports the research question and no external message has been sent.
