# Security and data policy

## Supported versions

The latest release receives security and privacy fixes.

## Report a vulnerability

Use GitHub Security Advisories for vulnerabilities. Do not include live credentials, private customer data, or exploitable production details in a public issue.

## Default safety boundary

Signal to Growth creates plans, analyses, and drafts. It does not authorize email, direct messages, publishing, deletion, refunds, deployment, billing changes, or other external writes.

External execution requires:

1. an explicit human approval;
2. a named target and owner;
3. a validated action artifact;
4. a retained audit record.

## Data handling

- Use synthetic or explicitly licensed data in public fixtures.
- Classify imported customer data before processing.
- Preserve source locators without exposing restricted content.
- Scan for private data before producing public output.
- Never store API keys or credentials in artifacts.
